Hive Server

This puts the family's music server on this Mac. It starts when you sign in and keeps running in the background.

  • Install Tailscale and sign in first, so the family's phones can reach home.
  • Your music goes in Music → Hive (you can add other folders in Hive Admin).
  • Afterwards, open Applications → Hive Server → Open Hive Admin.

Updating? Hive makes a backup first, then carries on with everything as it was.
