Hive 0.4.0: everyday family use (M4).

**Install**

| On | Download |
| --- | --- |
| The home PC (Windows) | `HiveServerSetup-0.4.0.exe` |
| A home Mac, instead | `HiveServer-0.4.0-mac.pkg` (Apple silicon) |
| Android phones | `Hive-0.4.0.apk` |
| Windows computers | `HiveSetup-0.4.0.exe` |
| Macs | `Hive-0.4.0-mac.dmg` |
| iPhones | through TestFlight, once the Apple account is set up |

**New**

- Backups every night, restore from Hive Admin, and moving Hive to another computer.
- The Windows home PC installer: Hive starts at boot and backs up before every update.
- System health, logs, and an email when something needs a look.
- Carry on listening on another of your devices from the same place.
- Simple mode, light and dark, the tray / menu-bar player and mini player, output and exclusive mode on Windows.
- Hive Admin: correct a song's details, and tidy up the same song in two files.

`SHA256SUMS.txt` lists each file's checksum.
